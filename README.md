# Trainary - Modern Fitness Web Platform

Next.js, TypeScript ve Tailwind CSS ile oluşturulmuş modern, yüksek performanslı bir fitness web platformu.  
*A modern, high-performance fitness web platform built with Next.js, TypeScript, and Tailwind CSS.*

*Personalized Fitness Programs: Customized workout plans based on user goals*

📱 **Duyarlı Tasarım**: Tüm cihazlarda uyumluluğu sağlayan mobil öncelikli yaklaşım  
*Responsive Design: Mobile-first approach ensuring compatibility across all devices*

*Modern UI: Clean, accessible interface with intuitive navigation*

⚡ **Performans Optimizasyonu**: Hızlı yükleme süreleri ve SEO dostu yapı  
*Performance Optimized: Fast loading times and SEO friendly structure*

🎯 **Animasyonlar**: Kullanıcı deneyimini artıran etkileyici animasyonlar  
*Animations: Captivating animations enhancing user experience*

## 🔒 Güvenlik Özellikleri | Security Features

Trainary, kullanıcı verilerinin güvenliği ve gizliliği konusunda en yüksek standartları gözetmektedir:  
*Trainary maintains the highest standards for user data security and privacy:*

🛡️ **CSRF Koruması**: Tüm formlarda Cross-Site Request Forgery saldırılarına karşı güçlü koruma  
*CSRF Protection: Strong protection against Cross-Site Request Forgery attacks on all forms*

🔐 **XSS Önleme**: Kullanıcı girdileri güvenli şekilde sanitize edilerek Cross-Site Scripting saldırıları engellenmekte  
*XSS Prevention: User inputs are safely sanitized to prevent Cross-Site Scripting attacks*

🔒 **Güvenli Şifreleme**: Kullanıcı şifreleri modern şifreleme algoritmalarıyla hashlenerek saklanmakta  
*Secure Encryption: User passwords are stored using modern hashing algorithms*

⚔️ **Rate Limiting**: Brute force saldırılarını engellemek için akıllı istek sınırlandırma sistemi  
*Rate Limiting: Smart request limiting system to prevent brute force attacks*

📊 **Güvenli Veri İşleme**: Tüm kullanıcı verileri işlenirken GDPR uyumlu süreçler takip edilmekte  
*Secure Data Processing: GDPR compliant processes when handling all user data*

🛑 **İçerik Güvenliği Politikası**: Yetkisiz kaynaklardan kod ve içerik yüklenmesini engelleyen CSP yapılandırması  
*Content Security Policy: CSP configuration preventing loading of code and content from unauthorized sources*

## 🔨 Projeyi Derleme ve Çalıştırma Kılavuzu | Build and Run Guide

Bu bölüm, projeyi geliştirmek, derlemek ve canlı ortama deploy etmek isteyen geliştiriciler için detaylı adımları içermektedir.  
*This section contains detailed steps for developers who want to develop, build, and deploy the project to a live environment.*

### 🔧 Geliştirme Ortamı Gereksinimleri | Development Environment Requirements

- Node.js 16.0.0 veya daha yeni sürüm | *or newer version*
- npm 8.0.0 veya daha yeni sürüm | *or newer version*
- Git

### 🚀 Geliştirme Ortamı Kurulumu | Setting Up Development Environment

1. **Repoyu klonlayın | Clone the repository:**
   ```bash
   git clone https://github.com/ByVarol/trainary.git
   cd trainary
   ```

2. **Bağımlılıkları yükleyin | Install dependencies:**
   ```bash
   npm install
   ```

3. **Ortam değişkenlerini ayarlayın | Set up environment variables:**
   - `.env.local.example` dosyasını `.env.local` olarak kopyalayın | *Copy the file as:*
     ```bash
     cp .env.local.example .env.local
     ```
   - `.env.local` dosyasını açın ve gerekli değişkenleri ayarlayın | *Open the file and set the necessary variables:*
     ```
     API_URL=http://localhost:3000/api
     NEXT_PUBLIC_SITE_URL=http://localhost:3000
     # Diğer ortam değişkenlerini projenin ihtiyaçlarına göre ayarlayın
     # Set other environment variables according to project needs
     ```

4. **Geliştirme sunucusunu başlatın | Start the development server:**
   ```bash
   npm run dev
   ```
   Bu komut, Next.js geliştirme sunucusunu başlatacak ve proje http://localhost:3000 adresinde erişilebilir olacaktır.  
   *This command will start the Next.js development server and the project will be accessible at http://localhost:3000.*

### 🧪 Test Etme | Testing

Projeyi test etmek için aşağıdaki komutları kullanabilirsiniz:  
*You can use the following commands to test the project:*

1. **Lint kontrolü | Lint check:**
   ```bash
   npm run lint
   ```

2. **Birim testleri çalıştırma | Run unit tests:**
   ```bash
   npm run test
   ```

3. **Tüm testleri çalıştırma | Run all tests:**
   ```bash
   npm run test:all
   ```

### 🏗️ Derleme ve Canlı Ortama Aktarma | Building and Deploying to Production

1. **Projeyi build etme | Build the project:**
   ```bash
   npm run build
   ```
   Bu komut, projeyi `.next` klasörüne derleyecektir.  
   *This command will compile the project to the `.next` folder.*

2. **Build'i local olarak test etme | Test the build locally:**
   ```bash
   npm run start
   ```
   Bu komut, derlenen projeyi local sunucuda çalıştıracak ve http://localhost:3000 adresinde erişilebilir olacaktır.  
   *This command will run the compiled project on a local server and make it accessible at http://localhost:3000.*

3. **Canlı ortama deploy etme | Deploy to production:**

   #### Vercel ile Deploy (Önerilen) | Deploy with Vercel (Recommended):
   
   Vercel, Next.js uygulamaları için en optimize çözümdür.  
   *Vercel is the most optimized solution for Next.js applications.*
   
   ```bash
   # Vercel CLI'yi global olarak yükleyin | Install Vercel CLI globally
   npm install -g vercel
   
   # Projeyi deploy edin | Deploy the project
   vercel
   ```
   
   Ya da Vercel hesabınızı GitHub reponuza bağlayarak otomatik deploy ayarlayabilirsiniz.  
   *Or you can set up automatic deployment by connecting your Vercel account to your GitHub repo.*

   #### Diğer Hosting Seçenekleri | Other Hosting Options:
   
   **Netlify ile | With Netlify:**
   ```bash
   # Netlify CLI'yi global olarak yükleyin | Install Netlify CLI globally
   npm install -g netlify-cli
   
   # Projeyi build edin | Build the project
   npm run build
   
   # Projeyi deploy edin | Deploy the project
   netlify deploy
   ```
   
   **Geleneksel Hosting | Traditional Hosting:**
   ```bash
   # Projeyi build edin | Build the project
   npm run build
   
   # Statik çıktıları oluşturun (isteğe bağlı) | Generate static outputs (optional)
   npm run export
   
   # Çıktı dosyalarını (out/ veya .next/) sunucunuza yükleyin
   # Upload output files (out/ or .next/) to your server
   ```

### 🐳 Docker ile Çalıştırma | Running with Docker

Trainary'i Docker ile çalıştırmak için:  
*To run Trainary with Docker:*

1. **Docker imajını oluşturun | Build the Docker image:**
   ```bash
   docker build -t trainary .
   ```

2. **Docker konteynerini çalıştırın | Run the Docker container:**
   ```bash
   docker run -p 3000:3000 trainary
   ```

   Bu komutlar, uygulamayı Docker konteynerinde çalıştıracak ve http://localhost:3000 adresinde erişilebilir kılacaktır.  
   *These commands will run the application in a Docker container and make it accessible at http://localhost:3000.*

### 🔧 Olası Sorunlar ve Çözümleri | Possible Issues and Solutions

1. **Bağımlılık Hataları | Dependency Errors:**
   ```bash
   npm clean-install
   ```

2. **Build Hataları | Build Errors:**
   - `.next` klasörünü silin ve yeniden build edin | *Delete the `.next` folder and rebuild:*
     ```bash
     rm -rf .next
     npm run build
     ```

3. **API Bağlantı Sorunları | API Connection Issues:**
   - `.env.local` dosyasında API_URL değişkeninin doğru ayarlandığından emin olun | *Make sure the API_URL variable is set correctly in the `.env.local` file*
   - Ağ bağlantınızı kontrol edin | *Check your network connection*
   - CORS hatası varsa, API sunucunuzun doğru CORS başlıklarını gönderdiğinden emin olun | *If there's a CORS error, make sure your API server is sending the correct CORS headers*
